# Алтайский Мёд — Натуральный мёд с пасеки

Современный и стильный интернет-магазин натурального алтайского мёда.

## Особенности

- **Широкий ассортимент**: Описание и цены для различных сортов мёда (Эспарцетовый, Дягилевый, Горный и др.).
- **Интерактивный прайс-лист**: Удобная таблица с ценами и возможностью предпросмотра упаковки (наведение на изображение банки увеличивает его).
- **Корзина покупок**: Простое управление выбранными товарами.
- **Интеграция с WhatsApp**: Быстрое оформление заказа через мессенджер.
- **Адаптивный дизайн**: Сайт отлично выглядит как на десктопах, так и на мобильных устройствах.

## Технологии

- React 18+
- TypeScript
- Tailwind CSS 4
- Motion (для анимаций)
- Lucide React (иконки)
- Vite (инструмент сборки)

## Начало работы

### Требования

- Node.js (рекомендуется LTS версия)
- npm

### Установка

1. Клонируйте репозиторий:
   ```bash
   git clone <url-репозитория>
   cd altai-honey-shop
   ```

2. Установите зависимости:
   ```bash
   npm install
   ```

### Запуск в режиме разработки

Для запуска сервера разработки выполните:
```bash
npm run dev
```
Сайт будет доступен по адресу `http://localhost:3000`.

### Сборка для продакшена

Для создания оптимизированной сборки проекта:
```bash
npm run build
```
Результаты сборки будут находиться в папке `dist/`.

## Структура проекта

- `src/App.tsx` — Основной компонент приложения.
- `src/image/` — Папка с изображениями товаров.
- `src/index.css` — Глобальные стили и конфигурация Tailwind.
- `src/env.d.ts` — Определения типов для ассетов.
